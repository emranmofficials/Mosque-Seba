# 🕌 মসজিদ সেবা (Mosque Seba) — Supabase ব্যাকএন্ড সেটআপ গাইড

এই গাইডের মাধ্যমে আপনি খুব সহজেই ৩ মিনিটের মধ্যে **মসজিদ সেবা** অ্যাপের জন্য একটি সম্পূর্ণ বিনামূল্যে ক্লাউড ব্যাকএন্ড ডেটাবেজ সেটআপ করতে পারবেন।

---

## 🚀 ধাপ ১: Supabase ক্লাউড প্রজেক্ট তৈরি (১ মিনিট)

1. [https://supabase.com](https://supabase.com) ওয়েবসাইটে যান এবং আপনার GitHub বা Google একাউন্ট দিয়ে **Sign In** করুন।
2. **New Project** বাটনে ক্লিক করুন।
3. নিচের তথ্যগুলো পূরণ করুন:
   - **Name:** `Mosque-Seba` (বা আপনার মসজিদের নাম)
   - **Database Password:** একটি শক্তিশালী পাসওয়ার্ড দিন এবং সংরক্ষণ করুন।
   - **Region:** `Singapore (ap-southeast-1)` বা `India (ap-south-1)` নির্বাচন করুন (বাংলাদেশের জন্য দ্রুতগতির)।
4. **Create new project** বাটনে ক্লিক করুন। ডেটাবেজ প্রস্তুত হতে প্রায় ১ মিনিট সময় লাগবে।

---

## 💾 ধাপ ২: মাস্টার ডেটাবেজ স্কিমা চালু করা (১ মিনিট)

1. আপনার Supabase ড্যাশবোর্ডের বাম পাশের মেন্যু থেকে **SQL Editor** এ ক্লিক করুন।
2. **New query** বাটনে ক্লিক করুন।
3. প্রজেক্টের `supabase/full_schema_setup.sql` ফাইলের সমস্ত কোড কপি করে SQL Editor এ পেস্ট করুন।
4. নিচে ডানদিকের সবুজ **Run** বাটনে ক্লিক করুন (কিবোর্ড শর্টকাট: `Ctrl + Enter` বা `Cmd + Enter`)।
5. কয়েক সেকেন্ডের মধ্যে `Success. No rows returned` মেসেজ আসবে।
   - আপনার সমস্ত টেবিল (`mosques`, `profiles`, `members`, `transactions`, `notices`, `chanda_payments`, ইত্যাতি) স্বয়ংক্রিয়ভাবে তৈরি হয়ে গেছে।
   - সকল সিকিউরিটি রুলস (Row Level Security - RLS) এবং সিকিউর ফাংশনস চালু হয়ে গেছে।

---

## 🔑 ধাপ ৩: API Credentials সংগ্রহ করা (৩০ সেকেন্ড)

1. বাম পাশের মেন্যু থেকে **Project Settings** (গিয়ার আইকন ⚙️) এ যান।
2. সাবমেন্যু থেকে **API** অপশনে ক্লিক করুন।
3. সেখান থেকে দুটি তথ্য কপি করুন:
   - **Project URL:** যেমন: `https://xyzcompany.supabase.co`
   - **Project API Keys:** এর অধীনে থাকা `anon` / `public` কীটি কপি করুন (এটি `eyJhbGciOi...` দিয়ে শুরু হয়)।

---

## 📱 ধাপ ৪: মসজিদ সেবা অ্যাপে ব্যাকএন্ড সংযোগ ও সিঙ্ক (৩০ সেকেন্ড)

1. আপনার ফোনে **মসজিদ সেবা (Mosque Seba)** অ্যাপ খুলুন।
2. **প্রোফাইল / একাউন্ট** ট্যাবে যান।
3. **"নিরাপত্তা ও ডেটা সিঙ্ক"** সেকশনের অধীনে থাকা **"অফলাইন ডেটা ও ক্লাউড সিঙ্ক"** অপশনে ট্যাপ করুন।
4. ডায়ালগে আপনার কপি করা:
   - **Supabase Project URL**
   - **Supabase Anon API Key**
   পেস্ট করুন এবং **"টেস্ট কানেকশন"** বাটনে ট্যাপ করুন।
5. কানেকশন সফল হলে **"এখনই ক্লাউডে সিঙ্ক করুন"** বাটনে ট্যাপ করুন!
6. আপনার ডিভাইসের সমস্ত তথ্য ক্লাউডে সিঙ্ক হয়ে যাবে এবং যেকোনো নতুন ডাটা স্বয়ংক্রিয়ভাবে ক্লাউডে ব্যাকআপ থাকবে।

## 🔒 ডেটা নিরাপত্তা ও অফলাইন বৈশিষ্ট্য

* **১০০% অফলাইন সাপোর্ট:** ইন্টারনেট না থাকলেও অ্যাপটি নিরবচ্ছিন্নভাবে চলবে। ডিভাইস ইন্টারনেটের সাথে যুক্ত হওয়ামাত্রই ডেটা ক্লাউডে সিঙ্ক হয়ে যাবে।
* **মাল্টি-টেন্যান্ট সিকিউরিটি (RLS):** এক মসজিদের ডেটা অন্য মসজিদের কেউ দেখতে বা পরিবর্তন করতে পারবে না।
* **প্রমাণিত ব্যাকএন্ড:** স্বয়ংক্রিয় ভাউচার সিরিয়াল, ক্যাশলেস ট্রানজ্যাকশন রিভার্সাল এবং জালিয়াতিমুক্ত অডিট লগ সিস্টেম সংহত।
